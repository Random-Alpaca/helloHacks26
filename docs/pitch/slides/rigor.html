Not just a wrapper

Engineering discipline you can actually check.

Zero credential handling

Every login opens a real, visible browser window the student signs into themselves. Our code never sees a password.

JSON only, behind login

Behind a CWL session we read only structured API responses - never scrape a logged-in page's HTML.

Honest about what's unverified

Every adapter's own docstring states what's a cited fact versus a reasoned guess, in plain words.

Failure never cascades

One malformed course or a down server can't wipe out every other course's already-fetched data.

Verified against the real thing

Built and smoke-tested against real UBC endpoints during the hackathon, not just against documentation.

Caught before it shipped

A live test against the real Bookstore caught a bug that would have hammered an entire department with requests - fixed before merge.
